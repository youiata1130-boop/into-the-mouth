# 口に入る デジタル試作

ボードゲーム「口に入る」のルール検証用プロトタイプです。

## 起動

```powershell
npm install
npm run dev
```

ブラウザで <http://localhost:5173/> を開きます。

`npm run build` を実行すると、`dist/index.html` に単体表示用のビルドも作成されます。

## ソース構成

- `src/main.ts`: ゲーム進行、CPUスケジュール、画面描画の統括
- `src/game/config.ts`: カード枚数や制限時間などの設定
- `src/game/model.ts`: カードとプレイヤーの型定義
- `src/game/deck.ts`: 山札作成、ドロー、公開札の補充
- `src/game/rules.ts`: 捕食、得点候補、親得点の計算
- `src/game/random.ts`: シャッフルと乱数処理
- `src/ui/dom.ts`: フォーカス復元などのDOM補助
- `src/styles.css`: 画面スタイル

## 実装済みの主なルール

- 4人から6人で遊べます。
- 全員が1回ずつ親を担当します。
- 1回の親ラウンドは必ず3トライ行い、3トライ終了後に親を交代します。
- 各子プレイヤーは、魚2を3枚、魚3を3枚、魚4を2枚、魚5を1枚、魚6を1枚、毒魚を1枚の計11枚を山札にします。
- 親ラウンド開始時に山札を補給し、子は山札から3枚を公開します。
- 公開カードは使用後に自動補充し、山札・公開カード・使用済みカードは3トライを通して引き継ぎます。
- 山札と公開カードを使い切った子は、その親ラウンド中は行動できません。
- トライ開始時、箱には餌カード「1」が入ります。
- カードは箱に入った順に処理します。現実の箱では、下にあるカードほど先に出たカードです。
- トライ中、箱のカードは表向きに重ねます。一番上のカードは内容が見え、それより下のカードは端だけが見えて枚数を確認できます。
- トライ終了時にカードを入った順に公開し、逃げた位置または親が口を閉じた位置を確認します。
- 魚カードは数字に関係なく出せます。
- 口が開いている間、同じ魚2をドラッグして重ねると強さ4の群れ、同じ魚3を重ねると強さ6の群れになります。
- 群れを作って空いた公開枠には、山札が残っていれば即座に1枚補充します。
- 群れは1枚の魚として扱い、再度重ねたり分けたりはできません。捕食・毒魚・親得点では群れの強さ4または6を使います。
- 新しい魚は、直前のカードから逆順に見て、自分より小さい数字カードを食べます。
- 自分以上の魚、有効な毒魚、成功した逃げるカード、毒魚で得点化済みの魚にぶつかると捕食は止まります。
- 食べた魚が得点候補を持っていた場合、その候補も新しい魚へ引き継ぎます。
- 逃げるは公開カード1枚を裏向きで使用します。
- 逃げ成功時は、対象の魚が食べていたカードの合計だけ得点します。自分の魚カード自体は含みません。
- 逃げる権利がない子が裏向きで出したカードは使用済みになりますが、効果も得点価値も持ちません。
- 親が口を閉じると、毒魚、逃げる、毒魚で得点化済みの魚を除いた数字カードを親が得点します。
- 毒魚は、別の子が次に出した魚1枚を毒魚プレイヤーの確定得点にします。
- 毒魚を出した本人が続けて魚を出した場合、その魚は効果も得点価値も持ちません。
- 有効な毒魚の後に別の毒魚が出た場合、得点の権利は後から毒魚を出した子へ移ります。
- 有効な毒魚があっても、得点候補を持つ子は通常どおり逃げられます。
- 親は有効な毒魚を3秒以内に取り除けます。
- 3秒以内に取り除けなかった場合は、毒魚プレイヤーが10点を獲得し、親は0点でトライ終了です。
- 有効な毒魚が残ったまま親が口を閉じた場合も、毒魚プレイヤーが10点を獲得し、親は0点です。
- 毒魚は1枚の魚に発動したら自動で無効になります。
- 逃げ対象が複数ある場合は、その子が最後に出した有効な得点候補を対象にします。
- 同点時は同点勝利として表示します。
